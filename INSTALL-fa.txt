■ این چیست؟

  جایگزین کاتالوگ اکسل. همان ساختار، اما:
    • سود هر سفارش خودکار حساب می‌شود
    • «دفتر نداشتیم» به تحلیل تبدیل می‌شود
    • تصمیم انبار بر اساس دادهٔ واقعی، نه حدس
    • گزارش ماهانهٔ شمسی
    • خروجی اکسل هر وقت خواستید

  همه‌چیز روی کامپیوتر خودتان می‌ماند. نه اینترنت لازم دارد،
  نه اشتراک ماهانه، نه کسی به داده‌هایتان دسترسی دارد.


■ پیش‌نیاز

  فقط XAMPP. اگر ندارید:
    ۱. به نشانی apachefriends.org بروید
    ۲. نسخهٔ ویندوز را دانلود و نصب کنید
    ۳. پیشنهاد: در مسیر پیش‌فرض C:\xampp نصب شود


■ نصب — چهار گام

  گام ۱ — کپی پوشه
  ─────────────────
  کل پوشهٔ «ghatehresan-app» را کپی کنید داخل:

      C:\xampp\htdocs\

  یعنی در نهایت باید این مسیر وجود داشته باشد:

      C:\xampp\htdocs\ghatehresan-app\public\index.php


  گام ۲ — روشن کردن آپاچی
  ────────────────────────
  • XAMPP Control Panel را باز کنید
  • روبه‌روی Apache دکمهٔ Start را بزنید
  • باید سبز شود

  ⚠ اگر Apache سبز نشد و خطای پورت داد، بخش «مشکلات» پایین را ببینید.


  گام ۳ — باز کردن در مرورگر
  ───────────────────────────
  این نشانی را در مرورگر بزنید:

      http://localhost/ghatehresan-app/public/

  در اولین اجرا، صفحهٔ «راه‌اندازی اولیه» باز می‌شود.
  یک نام کاربری و رمز عبور حداقل ۸ نویسه‌ای برای مدیر بسازید.
  بعد از آن، سامانه فقط پس از ورود قابل استفاده است.


  گام ۴ — دادهٔ نمونه (اختیاری)
  ─────────────────────────────
  پس از ورود، به «تنظیمات» بروید و دکمهٔ «ساخت دادهٔ نمونه» را بزنید.
  چند کالا و سفارش ساختگی ساخته می‌شود تا ببینید هر صفحه چه کار می‌کند.

  وقتی کارتان راه افتاد، در همان صفحه «پاک کردن همهٔ داده‌ها» را بزنید
  و اطلاعات واقعی خودتان را وارد کنید.


■ کاربران و نقش‌ها

  مدیر اولیه از منوی «کاربران» می‌تواند برای هر همکار حساب جدا بسازد:
    • مدیر کل: دسترسی کامل، تنظیمات، پشتیبان‌گیری و مدیریت کاربران
    • مدیر عملیاتی: همهٔ عملیات روزمره، بدون تنظیمات و مدیریت کاربران
    • فروشنده: کالا، سفارش، مشتری، دفتر نداشتیم و گزارش فروش
    • انباردار: مشاهدهٔ کالا، انبار، کاردکس، تصمیم انبار و تأمین‌کنندگان

  لینک‌های غیرمجاز در منو پنهان می‌شوند و عملیات حساس در سمت سرور نیز
  بررسی می‌شوند. حداقل یک مدیر کل فعال همیشه باید باقی بماند و مدیر جاری
  نمی‌تواند حساب خودش را غیرفعال یا نقش خود را تنزل دهد.

  هر کاربر از بخش «حساب من» می‌تواند رمز خودش را تغییر دهد.
  مدیر کل نیز در «گزارش فعالیت» ورودها و عملیات حساس کاربران را می‌بیند؛
  رمز عبور هیچ‌وقت در این گزارش ذخیره نمی‌شود.


■ میان‌بر روی دسکتاپ

  ۱. روی دسکتاپ راست‌کلیک → New → Shortcut
  ۲. این را وارد کنید:
       http://localhost/ghatehresan-app/public/
  ۳. اسمش را بگذارید: قطعه‌رسان


■ پشتیبان‌گیری — مهم‌ترین عادت

  همهٔ داده‌ها در یک فایل است:

      ghatehresan-app\storage\ghatehresan.sqlite

  هفته‌ای یک بار:
    • یا از داخل سامانه: تنظیمات ← «دانلود فایل پشتیبان کامل»
    • یا همان فایل را دستی کپی کنید

  فایل پشتیبان را جایی بیرون از این کامپیوتر نگه دارید —
  فلش، هارد اکسترنال، یا فضای ابری.

  یک هارد که بسوزد، کل سابقهٔ کسب‌وکارتان می‌رود.


■ استفاده روی گوشی (در همان شبکهٔ خانه یا مغازه)

  ۱. روی کامپیوتر، در Command Prompt بزنید:  ipconfig
  ۲. عددی مثل 192.168.1.5 را پیدا کنید (IPv4 Address)
  ۳. روی گوشی، در مرورگر بزنید:
       http://192.168.1.5/ghatehresan-app/public/

  ⚠ هر دو دستگاه باید به یک وای‌فای وصل باشند.
  ⚠ ممکن است لازم باشد در Windows Firewall اجازهٔ Apache را بدهید.


■ اگر خواستید از MySQL استفاده کنید (اختیاری)

  به‌صورت پیش‌فرض سامانه از SQLite استفاده می‌کند که هیچ تنظیماتی
  نمی‌خواهد. اگر دلیل خاصی دارید که MySQL بخواهید:

  ۱. در XAMPP، MySQL را هم Start کنید
  ۲. به http://localhost/phpmyadmin بروید
  ۳. یک پایگاه داده بسازید به نام: ghatehresan
     (Collation را روی utf8mb4_persian_ci بگذارید)
  ۴. فایل زیر را با Notepad باز کنید:
        ghatehresan-app\app\config.php
  ۵. این خط را پیدا کنید:
        'driver' => 'sqlite',
     و به این تغییر دهید:
        'driver' => 'mysql',
  ۶. صفحه را در مرورگر رفرش کنید

  توصیه: اگر دلیل خاصی ندارید، SQLite را نگه دارید. ساده‌تر است و
  پشتیبان‌گیری‌اش فقط کپی کردن یک فایل است.


■ مشکلات رایج

  «Apache سبز نمی‌شود / خطای پورت ۸۰»
     معمولاً اسکایپ یا IIS پورت ۸۰ را گرفته.
     راه‌حل سریع: در XAMPP روی Config کنار Apache بزنید →
     httpd.conf → عدد ۸۰ را به ۸۰۸۰ تغییر دهید → ذخیره → Start
     بعد نشانی می‌شود:
        http://localhost:8080/ghatehresan-app/public/

  «صفحه سفید است»
     مسیر را اشتباه زده‌اید. آخرش باید /public/ داشته باشد.

  «Object not found / 404»
     پوشه در جای درست کپی نشده. مسیر باید دقیقاً این باشد:
        C:\xampp\htdocs\ghatehresan-app\public\index.php

  «خطای پایگاه داده»
     پوشهٔ storage باید قابل نوشتن باشد.
     راست‌کلیک روی پوشه → Properties → تیک Read-only را بردارید.

  «فارسی به‌هم‌ریخته نشان می‌دهد»
     مرورگر را یک بار با Ctrl+F5 رفرش کنید.

  «می‌خواهم خطاها را ببینم»
     فایل app\config.php را باز کنید و 'debug' => false را
     به 'debug' => true تغییر دهید. بعد از رفع مشکل، برش گردانید.
