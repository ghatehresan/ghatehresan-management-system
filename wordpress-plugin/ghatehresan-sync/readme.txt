=== قطعه‌رسان — همگام‌سازی ووکامرس ===
Contributors: ghatehresan
Tags: woocommerce, inventory, orders, sync
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 0.1.0

اتصال ووکامرس به سامانهٔ مدیریت قطعه‌رسان برای همگام‌سازی کالا، قیمت، موجودی و سفارش.

== نصب ==

1. پوشهٔ `ghatehresan-sync` را داخل `wp-content/plugins/` کپی کنید.
2. از پیشخوان وردپرس، افزونه را فعال کنید.
3. ووکامرس باید فعال باشد.
4. در سامانهٔ مدیریت به «تنظیمات ← اتصال وب‌سایت وردپرسی» بروید.
5. کلیدهای API را بسازید و اتصال را فعال کنید.
6. در ووکامرس به «ووکامرس ← همگام‌سازی قطعه‌رسان» بروید.
7. آدرس کامل `public/api.php`، کلید و رمز API را وارد کنید.
8. اگر واحد قیمت سایت ریال و سامانه تومان است، ضریب تبدیل را `۰٫۱` بگذارید؛ در حالت یکسان `۱` است.
9. ابتدا «تست اتصال» و سپس «همگام‌سازی همین حالا» را اجرا کنید.

== رفتار همگام‌سازی ==

* سامانهٔ مدیریت مرجع قیمت و موجودی است.
* کالاها، قیمت و موجودی هر ۱۵ دقیقه از سامانه به ووکامرس می‌آیند.
* سفارش جدید ووکامرس با شناسهٔ یکتا به سامانه ارسال می‌شود.
* اگر پاسخ ارسال سفارش قطع شود، صف retry سفارش را دوباره می‌فرستد و سفارش دوباره ثبت نمی‌شود.
* تغییر وضعیت سفارش در سامانه به وضعیت متناظر ووکامرس برمی‌گردد.
* ارتباط با HMAC، زمان درخواست و HTTPS انجام می‌شود.

== نکات امنیتی ==

* API را فقط روی HTTPS فعال کنید.
* کلیدها را در اختیار افراد غیرمجاز نگذارید.
* ساعت سرور وردپرس و سامانه باید تقریباً هماهنگ باشد؛ اختلاف بیش از پنج دقیقه درخواست را رد می‌کند.
* اتصال مستقیم وردپرس به فایل SQLite یا دیتابیس سامانه انجام نمی‌شود.
